# 2026-10-31: hopo 2.1.3, ring glow, taskbar icon, HTTP phone page

Owner's feedback on 2.1.2:
- Remove the colourful line that slides along the top of each box. Keep the white light that runs around the border.
- A pinned taskbar icon still shows the old icon.
- Hovering a device on Home shows a rounded box behind it. It should be a circle.
- The wave rings lost their glow. They need a much wider glow, and cleaner, smoother lines without jagged edges.
- All motion should be smooth.
- The phone page should use HTTP, because browsers warn that the HTTPS link is not trusted.

## Items

- [x] 1. **No coloured top line.** Remove the purple-to-mint sheen line and its glow from cards in the Windows app, the macOS/Linux app and the phone page. The white edge sweep stays.
- [x] 2. **Taskbar icon (Windows).** The old Explorer package (1.9.0.0, which cannot be rebuilt without the Windows SDK) gives the process its old "Lantoss" logo. Set the window's own taskbar identity (app ID, relaunch command, name "hopo" and the exe's icon), so the taskbar and pins use the hopo icon. An existing pin must be unpinned and pinned again.
- [x] 3. **Round device hover.** The hover background behind a device dot on Home is a circle (Windows and macOS/Linux).
- [x] 4. **Wave ring glow and clean lines** (Windows and macOS/Linux).
  - Draw each ring as smooth curves through its points instead of straight segments, so there are no corners.
  - Use a 0.7 px line.
  - Add a wide soft glow in two layers: 3.5 px at .22 and 9 px at .08 of the line's opacity, with no blur effect.
  - All three layers share one geometry per frame.
- [x] 5. **Smoother motion on fast screens (Windows).** WPF animations run at 60 frames per second by default. Allow up to 120, so 90/120/144 Hz screens get smooth motion. Slower screens still run at their own rate.
- [x] 6. **Phone page over HTTP.**
  - "Encrypt the phone page (HTTPS)" is off by default.
  - Existing installs switch to HTTP once: the setting is saved under a new name, so the old "on" value is not read.
  - Anyone who wants HTTPS can turn it back on in Settings.
  - Update the default check in SecurityTests.
- [x] 7. **Verify and release 2.1.3.**
  - Tests, UI regression and format check.
  - Rebuild the seven setup files and publish release v2.1.3.

## Verification

- `build.ps1 -Mode Test`: 279 checks passed, 1 skipped (symlink privilege).
  - The default check now expects HTTP.
  - The older fixtures and the HTTPS security checks turn HTTPS on explicitly, so the HTTPS option is still covered.
- `browser-ui.test.cjs`: 16 passed. `-Mode CheckFormat` passed. Both apps build with 0 warnings.
- Windows `--ui-regression`: 27 passed. In the Home and Settings renders the rings are smooth with a visible glow, and the cards have no coloured line.
- Taskbar identity: the same interop code ran in a scratch .NET 10 WPF window. All four values (relaunch command, icon, "hopo", app ID) read back as set.
- `verify-installer.ps1` passed (hopo 2.1.3). All six macOS/Linux packages passed `verify.cjs` and tar.exe, and the Mac bundles are sealed. The MSI was built from `work\msi-stage`.

## Differences

- macOS/Linux: the device dot was already a circle (44 px with a 22 px radius), so only the Windows hover changed.
- Item 2 needs one step from the owner: an old pin keeps its old icon until it is unpinned and pinned again.
