# hopo 2.5.4, fixes from the 2.5.3 break test

Fixes the findings from the break test report (https://claude.ai/artifact/Ru6bafXn7Gs5oejL4tcZ1V): 1 High, 12 Medium, 14 Low and 3 Info. IDs match the report. Where the fix differs from the plan, the note says why.

## Data files and startup
- [x] H1 History records keep at most 200 file rows and a 12 MB history budget, so metadata.json always stays below the load limit.
- [x] M3 A damaged sync-state.json or shared-notes.json falls back to its .bak, then to empty (the damaged file is kept aside), instead of stopping startup.
- [x] M4 A missing metadata.json with a metadata.json.bak present is recovered from the .bak, not replaced by a new identity.
- [x] M5 A briefly locked metadata.json is waited for (up to 5 s) instead of rolling back to the .bak; read-only data files no longer block saves.
- [x] M6 History is sized outside the state lock and finished records drop extra file rows in memory, so large histories no longer freeze the UI or silently cut history.
- [x] L8 Receive folder: refuse missing drives, network drives, drive roots, Windows/Program Files and paths over 200 characters. A bad saved field resets only that field.
- [x] L9 Duplicate or incomplete history records are cleaned at load instead of crashing startup or the History page. A transfer ID used by another PC can no longer overwrite its record.

## PC-to-PC and network
- [x] M1 Connect always shows the matching-code check for a new PC when "Ask before a new PC connects" is on.
- [x] M2 The .local name responder, LAN discovery and mDNS keep listening after a "connection reset" from a closed port.
- [x] M11 Changed from the plan: hiding all-PC shared folders from PCs paired without a code broke the intended approval-off home setup (four existing tests). Instead Settings now says plainly that with approval off any device on the Wi-Fi can connect and open folders shared with all PCs; approval stays on by default, and auto-connect is limited (L7).
- [x] L4 Background checks update only last-seen and address, so they can no longer undo Stop trusting, renames or blocks.
- [x] L5 Files written by sync get the downloaded-from-another-computer mark.
- [x] L6 Manifest validation is linear; the pre-TLS handshake limit is 5 s and the connection pool is 32; pairing is limited to 5 a minute per address (20 overall) instead of 5 overall.
- [x] L7 Auto-connect dials at most 3 devices at once and prunes old retry entries; one address can list at most 4 nearby devices; unchanged announcements refresh the pages at most every 2 s. The mDNS name hijack itself is part of how .local names work; the QR code (IP address) remains the safe way in.

## Sync
- [x] M7 Conflict copies of dotfiles get a valid name, for example "gitignore (conflict abc).gitignore".
- [x] M8 One unsupported, locked, linked or still-changing entry is skipped and named in the sync status instead of stopping the whole folder; a local file error mid-pass no longer stops the other files. Thumbs.db and Office ~$ lock files are not synced.
- [x] L11 Names are compared in NFC so a Mac's decomposed accents match Windows names, and each side keeps its own spelling. Case-only renames and deletions still do not sync, by design (nothing is ever deleted by sync).

## Phone page
- [x] M12 Refused files are marked in the list as soon as they are chosen, Send waits until they are removed, and the message names the file and the reason.
- [x] L1 Names over 180 characters say the name is too long; a chosen file that can no longer be read says so instead of "Connection lost".
- [x] L2 The chosen-files list scrolls inside a box, so Send stays near the list.
- [x] L3 Long names are cut with an ellipsis; the list header and notices no longer widen or wrap the page at 320 px. Names are shown without hidden formatting characters.
- [x] L14 JSON errors return a plain message without internal type names.
- [x] I1 Notes refuse right-to-left override and other text-direction characters.

## Apps, installer and UI
- [x] M9 --admin only works in Debug builds; release hopoUsers.exe ignores it.
- [x] M10 hopo Admin has its own registry keys (AdminDesktop settings, hopoAdmin Explorer menu, "hopo Admin" sign-in entry), so uninstalling one app no longer removes the other's; Launch at sign-in reads and writes the right entry in each app.
- [x] L10 Home shows "+N more" past 8 PCs and 6 phones; device-card buttons name their device for screen readers; Windows contrast themes are followed; the menu shows the real version.
- [x] L12 A device seen with a future time is not shown online forever; a certificate within 60 days of its end is renewed for the same key, so pairings keep working.
- [x] L13 Explorer selections are batched for 2 s after the last item, so one Share becomes one transfer.
- [x] I2 The Explorer C++ source launches hopoUsers.exe; uninstall removes this app's firewall rules (Windows asks once); one data folder cannot run twice through a trailing separator. The old Lantoss.exe, DLL and msix in app\ were left alone: app\ is a local build folder outside git.
- [x] I3 The Mac install script says the seal only shows the download is complete and points to the release checksum.
