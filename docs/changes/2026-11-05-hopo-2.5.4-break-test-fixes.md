# hopo 2.5.4, fixes from the 2.5.3 break test

Fixes every finding from the break test report (https://claude.ai/artifact/Ru6bafXn7Gs5oejL4tcZ1V): 1 High, 12 Medium, 14 Low and 3 Info. IDs match the report.

## Data files and startup
- [ ] H1 History records keep at most 200 file rows and a 12 MB history budget, so metadata.json always stays below the load limit.
- [ ] M3 A damaged sync-state.json or shared-notes.json falls back to its .bak, then to empty (the damaged file is kept aside), instead of stopping startup.
- [ ] M4 A missing metadata.json with a metadata.json.bak present is recovered from the .bak, not replaced by a new identity.
- [ ] M5 A briefly locked metadata.json is waited for (up to 5 s) instead of rolling back to the .bak; read-only data files no longer block saves.
- [ ] M6 History is sized outside the state lock and finished records drop extra file rows in memory, so large histories no longer freeze the UI or silently cut history.
- [ ] L8 Receive folder: refuse missing drives, network drives, drive roots, Windows/Program Files and paths over 200 characters. A bad saved field resets only that field.
- [ ] L9 Duplicate or incomplete history records are cleaned at load instead of crashing startup or the History page.

## PC-to-PC and network
- [ ] M1 Connect always shows the matching-code check for a new PC when "Ask before a new PC connects" is on.
- [ ] M2 The .local name responder and LAN discovery keep listening after a "connection reset" from a closed port.
- [ ] M11 With approval off, PCs that paired without a code check cannot open shared folders until marked verified, and auto-connect no longer pairs with unknown PCs.
- [ ] L4 Background checks update only last-seen and address, so they can no longer undo Stop trusting, renames or blocks.
- [ ] L5 Files written by sync get the downloaded-from-another-computer mark.
- [ ] L6 Manifest validation is linear; idle sockets get a shorter pre-TLS limit; pairing attempts are limited per address instead of globally.
- [ ] L7 Auto-connect is capped to a few dials at once and old entries are pruned; discovery changes are coalesced before the UI refreshes.

## Sync
- [ ] M7 Conflict copies of dotfiles get a valid name, for example ".gitignore (conflict abc).gitignore" becomes "gitignore (conflict abc).gitignore".
- [ ] M8 One unsupported, locked or linked entry is skipped and reported instead of stopping the whole folder scan.
- [ ] L11 Names are compared in NFC so a Mac's decomposed accents match Windows names; case-only renames sync.

## Phone page
- [ ] M12 Refused files are marked in the list, the send skips nothing silently, and the error names the file and the reason.
- [ ] L1 Names over 180 characters say the name is too long; an unreadable chosen file says it could not be read.
- [ ] L2 The chosen-files list scrolls inside a box, so Send stays near the list.
- [ ] L3 Long names are cut with an ellipsis at narrow widths; the list header no longer wraps awkwardly.
- [ ] L14 JSON errors return a plain message without internal type names.
- [ ] I1 Notes refuse right-to-left override and other hidden formatting characters.

## Apps, installer and UI
- [ ] M9 --admin only works in Debug builds; release hopoUsers.exe ignores it.
- [ ] M10 Uninstalling one app no longer removes the other's Explorer menu, settings or sign-in start; Launch at sign-in reads and writes the right entry in hopo Admin.
- [ ] L10 Home shows "+N more" past 8 devices; device-card buttons name their device for screen readers; Windows contrast themes are followed; the menu shows the real version.
- [ ] L12 A device seen with a future time is not shown online forever; an expiring identity certificate is renewed with the same key.
- [ ] L13 Explorer selections coalesce within a longer window so one Share becomes one transfer.
- [ ] I2 The Explorer C++ source launches hopoUsers.exe; stale files leave app\; firewall rules are removed on uninstall; one data folder cannot run twice through different spellings.
- [ ] I3 The Mac install script no longer claims an ad-hoc signature proves the app is unmodified.

## Verification
- [ ] Regression checks for the fixes above, build.ps1 -Mode Test, browser-ui.test.cjs and CheckFormat pass.
