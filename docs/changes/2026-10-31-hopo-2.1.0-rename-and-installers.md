## Kept as Lantoss on purpose

These names are never shown in the app, and changing them breaks upgrades or needs tools this PC doesn't have:
- The Windows program file stays `Lantoss.exe`. The Windows 11 Explorer menu is a native DLL and a signed package that start `Lantoss.exe` by name, and rebuilding them needs g++ and the Windows SDK, which aren't installed here (downloading them needs the owner's OK).
- For the same reason the Explorer menu still reads "Share with Lantoss".
- Data folders (`%LOCALAPPDATA%\Lantoss`, `~/.local/share/Lantoss`, `~/Library/Application Support/Lantoss`), so every setting, pairing and history carries over.
- Registry keys, pipe and lock names, cookie and header names, the macOS bundle identifier, namespaces and the repository.
