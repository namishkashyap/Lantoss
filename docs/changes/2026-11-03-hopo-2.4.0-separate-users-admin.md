# 2026-11-03: hopo 2.4.0, separate hopo Users and hopo Admin, smaller downloads

Owner's request:
- The download and install are far too big. Reduce them as much as possible.
- Rename Lantoss.exe to "hopo Users". "hopo Admin" stays.
- Remove the admin PIN and the switching buttons. Admin and user are two completely separate apps, each with its own exe and setup file, shared with the right people.

Measured on this PC before the change:
- The 2.3.0 install was 174 MB, because both apps came in one installer and each carries its own .NET.
- Unpacked runtime files from older versions add another 74 MB in %TEMP%\.net.

## Items

- [ ] 1. **Two separate apps and setups.**
  - hopo Users: `hopoUsers.exe` and `hopo-Users-Setup-2.4.0-x64.msi`. It installs to `%LOCALAPPDATA%\Programs\hopo` and upgrades earlier hopo installs, which removes the old `Lantoss.exe` and `hopoAdmin.exe`.
  - hopo Admin: `hopoAdmin.exe` and `hopo-Admin-Setup-2.4.0-x64.msi`. It has its own product code, folder (`Programs\hopo Admin`), Start menu entry and uninstall entry.
  - Each setup holds only its own app.
  - Both exes are also attached to the release as single-file apps that run without installing.
- [ ] 2. **No PIN and no switching.**
  - Remove the admin PIN prompt, Change PIN, "Open hopo Admin" and "Open hopo" from the apps, and remove the PIN code, its preference and its tests.
  - hopo Admin always shows everything. hopo Users always shows the user pages.
  - If both are installed on one PC they share its data, so opening one still closes the other.
- [ ] 3. **Rename.**
  - `Lantoss.exe` becomes `hopoUsers.exe` ("hopo Users": file description, window, taskbar and Start menu). Explorer, autostart, the firewall rule and the tray use whichever app is installed.
  - The right-click entry reads "Share with hopo".
  - Data folders, registry locations and protocol names stay as they are (kept for compatibility).
- [ ] 4. **Windows 11 Explorer package removed.**
  - The prebuilt native menu add-on can only start a file named `Lantoss.exe`, and it can't be rebuilt without the Windows SDK. It is no longer installed.
  - "Share with hopo" stays in the right-click menu: in Windows 11, under Show more options.
  - Setup removes the old package left by earlier versions. It also no longer asks for publisher trust or administrator approval.
- [ ] 5. **Smaller apps.**
  - Ship only English resources (`SatelliteResourceLanguages=en`): measured 86.4 MB down to 80.6 MB per exe.
  - With one app per setup, each download and install is about half of 2.3.0.
- [ ] 6. **Checks.** Update the tests that check the executable name for Explorer and the firewall. Update the installer checks for the two setups.
- [ ] 7. **Verify and release 2.4.0.**
  - Tests, UI regression and format check.
  - Build both setups and the six macOS/Linux packages, and publish v2.4.0 with the two exes.
  - Open a PR and merge it.
