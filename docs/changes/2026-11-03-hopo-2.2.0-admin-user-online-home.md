# 2026-11-03: hopo 2.2.0, admin and user modes, online-only Home, past connections

Owner's request:
- Home should show only the devices that are on the network right now. Old connections go on a separate page.
- The menu needs a Home button.
- Add two kinds of user. The admin sees everything and a normal user does not. Make them separate and explain how to run both.

The owner chose "two modes, one PC": a "hopo" app for users and a "hopo Admin" app that opens with a PIN. This change covers Windows only.

## Items

- [ ] 1. **Online-only Home.**
  - Home shows PCs that are online now (not blocked) and approved phones or browsers that are connected.
  - Offline PCs no longer appear on Home.
  - In user mode, Home shows only paired PCs, because connecting a new PC is an admin task.
- [ ] 2. **Past connections page (admin).**
  - A new menu page lists PCs that are offline now: paired, blocked or only seen before, newest "last seen" first.
  - Paired PCs can be unpaired and blocked PCs can be unblocked.
  - The Devices page shows only PCs that are online now and points to Past connections.
- [ ] 3. **Home in the menu.** A "Home" row with a house icon at the top of the menu.
- [ ] 4. **Admin and user modes.**
  - "hopo" opens in user mode. "hopo Admin" (`Lantoss.exe --admin`) asks for the admin PIN, or asks you to create one the first time.
  - The PIN is 4–12 digits. It is stored only as a salted PBKDF2-SHA256 hash in the preferences.
  - After 5 wrong tries, the PIN entry pauses for 30 seconds.
  - User mode shows Home, Send files, Text & links and Transfers.
  - Admin only: Devices, Past connections, Share a folder (Shared Spaces), Sync, History, Phone & browser and Settings.
  - In user mode, Home hides the Folder button. The Phone panel shows the QR code when browser sharing is on, and otherwise says to ask the admin.
  - The top bar badge shows ADMIN or USER.
  - The menu footer has "Admin mode…" in user mode, and "Switch to user mode" and "Change PIN" in admin mode.
  - Opening "hopo Admin" while "hopo" is already running switches the running window to admin mode after the PIN.
  - Tray, autostart and Explorer sharing open in user mode.
- [ ] 5. **Installer.** A "hopo Admin" Start menu shortcut. The installer check expects 4 shortcuts.
- [ ] 6. **Checks.**
  - Unit tests: PIN hashing and verification, and `--admin` parsing.
  - UI regression: the menu has Home and Past connections, user mode hides the admin pages, and an admin page opened in user mode falls back to Home.
- [ ] 7. **Verify and release 2.2.0.**
  - Tests, UI regression and format check.
  - Rebuild the seven setup files and publish v2.2.0.
  - Open a PR and merge it (the owner has given permission).

## Notes

- The PIN locks the hopo window, not the Windows account. Someone signed in as the same Windows user could still edit hopo's files on disk. For real separation, give each person their own Windows account.
