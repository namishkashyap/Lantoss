## Files

- **Added (43):**
  - The Explorer extension in `source/Explorer/`.
  - The installer scripts and WiX source in `installer/`.
  - New 1.9 sources: `LocalDns.cs`, `LocalNameService.cs`, `LocalBrowserAccess.cs`, `TextSharing.cs`, `SharedNotes.cs`, `SyncScanner.cs`, `NotesPage.cs`.
  - Desktop and shell-integration sources.
  - Three test files.
  - GCC, MinGW and WiX license notices.
  - Build reports and four UI screenshots in `previews/`.
- **Modified (58):** documentation, the browser portal, and the core, networking, UI and test sources.
- **Excluded by `.gitignore`:** `app/` (built executable), `*.msi`, `*.zip`, signing keys (`*.pfx`, `*.key`, `*.pem`) and runtime metadata.

## Checks before publishing

- The MSI SHA-256 matches `SHA256SUMS.txt`. All 19 packaged files match
  `payload-verification.json`.
- Scanned for private keys, tokens and personal paths. None found. IP addresses
  appear only as private-range test fixtures. `source/Explorer/Publisher.cer`
  is a public certificate.
- Reviewed the four screenshots in `previews/`. They show the development PC's
  Windows name and a paired device label, and nothing else identifying.

## Not verified in this change

- The build and tests were **not** re-run. This machine has no .NET 10 SDK. The
  results in `package-report.json` (234 C# checks, 25 native COM, 25 WPF, 16
  browser DOM) come from the original 1.9 build.
- The MSI and `Lantoss.exe` are unsigned. The Explorer DLL and MSIX use a
  development certificate.

## Open items

- **License:** the repository has no license for Lantoss itself. GitHub's
  "MIT License" label comes from `ASPNET_LICENSE.txt`, which is Microsoft's
  license for ASP.NET Core. Choose a license and add a root `LICENSE` file.
- **README:** older sections still say "Update both PCs to 1.5". Backups still use
  the legacy `.flowshare-versions` folder name.

## Rollback

The previous state is tagged `v1.6.0` (`1e28bdc`). To restore it, revert the merge
commit of PR #1 (`git revert -m 1 <merge-commit>`). Do not force-push `main`.
